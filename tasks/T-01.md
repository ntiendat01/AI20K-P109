## Mục tiêu
Thay thế boilerplate `AgentState` bằng `ProcurementAgentState` đúng schema ARCHITECTURE.md, rồi dựng lại graph với stub nodes cho tất cả các bước; graph phải compile và chạy qua cả 2 HITL checkpoint bằng dữ liệu cứng (không gọi LLM, không đọc PDF thật).

## Acceptance criteria

- [ ] `src/agents/state.py` export class `ProcurementAgentState(TypedDict, total=False)` với đủ 11 field: `case_id`, `pr_data`, `documents`, `raw_extractions`, `review_mode`, `normalized_quotes`, `tco_results`, `comparison_matrix`, `risk_flags`, `recommendation`, `human_feedback` — mỗi field kèm type annotation cụ thể (không dùng `Any` trừ khi CẦN QUYẾT).
- [ ] `src/agents/graph.py` khai báo đủ các node: `extract_documents`, `validate_extraction`, `human_review_extraction`, `normalize`, `decision_llm`, `evaluate`, `generate_evidence`, `human_review_recommendation`, `process_feedback`.
  - Các node xử lý (`extract_documents`, `normalize`,...) là stub `return {}` hoặc trả về dữ liệu cứng cơ bản.
  - Node `evaluate` (hoặc edge điều kiện tương ứng) phải có dữ liệu/logic cứng để quyết định nhánh (ví dụ: chuyển sang `generate_evidence` nếu đủ thông tin).
  - 2 node `human_review_extraction` và `human_review_recommendation` **phải implement cơ chế `interrupt()` (LangGraph HITL)**.
- [ ] `src/agents/graph.py` compile không lỗi: `build_graph()` trả về graph đã `.compile()` với `MemorySaver` checkpointer.
- [ ] `make lint` và `make typecheck` pass (không có lỗi ruff/mypy mới so với baseline).
- [ ] Test `tests/test_agents/test_graph.py` có case: gọi `graph.invoke(stub_input, config)` → graph chạy tới HITL-1 và raise `GraphInterrupt` (hoặc trả về snapshot pending), không raise exception khác.
- [ ] Test có case: resume sau HITL-1 → graph chạy tới HITL-2 và raise `GraphInterrupt` lần hai.
- [ ] Test có case: resume sau HITL-2 → graph chạy đến `END` mà không raise exception.
- [ ] `make test` pass (toàn bộ test suite).
