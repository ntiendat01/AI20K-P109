# T-18: Sửa image frontend (nginx) thiếu file khi build
Trạng thái: Todo   <!-- Todo | In Progress | In Review | Done -->
Phụ thuộc: không

## Mục tiêu
`docker build` của `frontend/Dockerfile` tạo ra image chạy được: trang tải đủ mọi module JS và gọi được API qua nginx proxy.

## Bối cảnh (đọc từ code, chưa chạy runtime)
- `frontend/Dockerfile` chỉ có `COPY index.html styles.css app.js /usr/share/nginx/html/`.
- `app.js` import `./features/auth/auth.js`; `router.js` import `features/*`, `config/`, `utils/`, `core/`. Các thư mục `core/`, `features/`, `config/`, `utils/` **không** được copy → trình duyệt báo 404 ở import đầu tiên, trang trắng.
- `frontend/nginx.conf` proxy `/api/` tới `http://backend:8000` (tên service Docker).
- `docker-compose.yml` ở gốc **không có** service frontend; compose chỉ chạy `backend`, mount `./frontend` và để FastAPI phục vụ UI ở `/ui/`. `Dockerfile` ở gốc đã `COPY frontend ./frontend` đủ.
- Hệ quả: lỗi chỉ lộ khi ai đó build image nginx riêng; luồng demo hiện tại (cổng 8000, `/ui/`) không bị ảnh hưởng.

## Yêu cầu
1. Image nginx chứa toàn bộ file tĩnh cần cho runtime: `index.html`, `styles.css`, `app.js`, `core/`, `features/`, `config/`, `utils/`.
2. Không đưa vào image các file không phục vụ web (`Dockerfile`, `nginx.conf`, `.dockerignore`).
3. Đường dẫn trong HTML/JS giữ nguyên (đang là đường dẫn tương đối; `API_ROOT` là `/api/v1` tuyệt đối nên chạy được cả ở `/` của nginx lẫn `/ui/` của FastAPI).
4. Không đổi mã JS, `nginx.conf`, `docker-compose.yml` hay `Dockerfile` gốc.

## Acceptance criteria
- [ ] `docker build -t procura-fe frontend/` thành công.
- [ ] `docker run --rm procura-fe find /usr/share/nginx/html -name '*.js'` liệt kê đủ mọi file `.js` có trong `frontend/` (so với `find frontend -name '*.js'`).
- [ ] Mọi import tương đối trong `frontend/**/*.js` đều trỏ tới file có trong image (kiểm bằng lệnh/script một lần, ghi kết quả vào báo cáo cuối; không thêm script vào repo trừ khi được duyệt).
- [ ] Chạy container cùng mạng với backend (alias `backend`): `GET /` trả 200 và `GET /api/v1/...` (ví dụ `/health` qua `/api/` hoặc endpoint công khai) đi qua proxy tới backend.
- [ ] `make check` pass (task không đổi Python; chỉ xác nhận không làm hỏng gì).
