## Mục tiêu
Hiện thực node `decision_llm` gọi Qwen3-8B để phân tích `tco_results`, `comparison_matrix`,
`risk_flags` rồi sinh danh sách top-N NCC được đề xuất (N do Buyer cấu hình, mặc định 3, tối đa 5)
kèm lý do bằng số liệu cụ thể; node `generate_evidence` đính kèm trích dẫn vị trí PDF cho từng
luận điểm (US-04.3a, US-04.3b). Không xử lý đặc biệt theo khoảng cách TCO.

## Thay đổi contract

- **`Recommendation` (TypedDict mới — `src/agents/state.py`):**
  ```python
  class EvidenceItem(TypedDict, total=False):
      field: str
      supplier: str
      page: int | None
      source: str
      edited_by_human: bool
      low_confidence: bool

  class RankedSupplier(TypedDict):
      rank: int
      supplier: str
      rationale: str
      evidence: list[EvidenceItem]

  class Recommendation(TypedDict, total=False):
      ranked: list[RankedSupplier]
      top_n: int
      error: str | None
  ```
  Đổi kiểu `recommendation` trong `ProcurementAgentState` từ `dict[str, object]` → `Recommendation`.
  **Breaking change với T-10** — implementer T-10 phải đọc task này trước khi làm.

- **`RawExtraction` (`src/agents/state.py`):** Thêm trường `page_number: int | None`.
  `extract_documents` có trách nhiệm ghi giá trị này trong quá trình OCR.

- **`top_n`** (`ProcurementAgentState`): Đã thêm `top_n: int | None`, mặc định 3, giá trị
  hợp lệ 3–5; ngoài khoảng này node tự fallback về 3.

- **`generate_evidence`**: Sửa để không ghi đè `comparison_matrix` và `risk_flags`;
  chỉ ghi vào `recommendation["ranked"]` (evidence nằm trong từng `RankedSupplier`).

- **`graph.py`**: Thêm pre-condition router (`check_data_ready`) và conditional edge
  `normalize → check_data_ready → decision_llm | END`.
