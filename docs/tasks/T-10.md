# T-10: HITL-2: Buyer phê duyệt hoặc phản hồi

Phụ thuộc: T-09

## Mục tiêu
Hiện thực đầy đủ node `human_review_recommendation` (HITL-2) để Buyer xem xét và phê duyệt
đề xuất NCC; node `buyer_decision_router` định tuyến sang `END` (approved) hoặc
`process_feedback` (revise); node `process_feedback` nhận phản hồi của Buyer, ghi vào state
rồi quay lại `decision_llm` để phân tích lại (US-04.3a).

## Thay đổi contract

- **`graph.py`**: Cạnh `process_feedback → END` hiện tại (dòng 62) **sai với spec** — phải đổi
  thành `process_feedback → decision_llm` để tạo vòng lặp revise. Đây là thay đổi cấu trúc
  graph, ảnh hưởng tất cả integration test.
 
- **`Recommendation` TypedDict (`src/agents/state.py`)**: Bổ sung 2 field mới so với T-09:
  ```python
  class Recommendation(TypedDict, total=False):
      ranked: list[RankedSupplier]
      top_n: int
      error: str | None
      feedback_processed: bool          # mới — T-10
      feedback_history: list[str]       # mới — T-10, append mỗi vòng revise
  ```
  `process_feedback` ghi cả 2 field này; `decision_llm` đọc `feedback_history` để có context
  đầy đủ qua nhiều vòng lặp. **Breaking change với tất cả code từng dùng `recommendation`.**

- **`revise_count: int`** thêm vào `ProcurementAgentState`. `process_feedback` tăng lên 1
  mỗi lần chạy. Giá trị mặc định 0, giới hạn 3. Khi `revise_count >= 3`, payload của
  `human_review_recommendation` thêm `"max_revise_reached": True` (không tự thoát —
  Buyer vẫn có thể tiếp tục góp ý).

- **`human_feedback`**: Giữ nguyên `dict[str, object]` không khai báo TypedDict riêng
  (tự do type, UI gửi gì thì lưu nấy).
